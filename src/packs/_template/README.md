# الگوی پک (مرجع قالب)

این پوشه نمونهٔ قالب یک پک است. موتور آن را بارگذاری نمی‌کند (نام پوشه با «_» شروع می‌شود).
برای ساختن پک جدید: این پوشه را کپی کن، نامش را به `packs/<id>/` تغییر بده، و `id` داخل `data.js` را هم عوض کن.

## ساختار

```
packs/<id>/
  data.js          ← meta، دسته‌ها، کتاب‌ها، واژه‌نامه (فقط یک بار)
  sessions/
    s01.js         ← هر جلسه یک فایل
    s02.js
  widgets/
    _shared.js     ← (اختیاری) توابع مشترک؛ اول بارگذاری می‌شود
    <key>.js       ← هر ویجت یک فایل؛ key همان نامی است که جلسه با ref صدا می‌زند
  problems.js      ← (اختیاری) مسائل
```

## قرارداد

- **جلسه:** `CourseRuntime.registerUnit("<id>", "sessions", { id, num, title, ... })`
  - `id` یکتا در کل پک؛ `num` ترتیب نمایش (عدد)
  - محتوا همان ساختار جلسه‌های قبلی است (`detail.sections[].blocks`، `concepts`، `formulas` و ...)
- **ویجت:** `CourseRuntime.registerPackSource("<id>", { widgets: { <key>: { title, desc, mount(box), unmount(box) } } })`
  - `<key>` باید با نام فایل یکی باشد؛ در جلسه با `{ type: "widget", ref: "<key>" }` صدا زده می‌شود.
  - ویجت هیچ ارجاعی به جلسه ندارد.
- **data.js:** `sessions: CourseRuntime.getUnits("<id>", "sessions")` را در COURSE بگذار.

## کشف خودکار

- پوشه‌ای که `data.js` دارد به‌عنوان پک شناخته می‌شود؛ پوشه یا فایلی که با «_» شروع شود نادیده گرفته می‌شود.
- برای غیرفعال کردن یک پک، پوشه‌اش را به «_نام» تغییر بده.
- اپ را از طریق Live Server یا `python -m http.server` از ریشهٔ پروژه باز کن.
- خطاهای قرارداد (id تکراری، واحد بدون id) در تب «راهنما → سلامت داده» نمایش داده می‌شوند.
