# پک ترمودینامیک (Zemansky)

بر اساس **Heat and Thermodynamics**, 7th ed. — Mark W. Zemansky & Richard H. Dittman.

## محدودهٔ فعلی

- **فصل ۱**: دما و قانون صفرم
- **فصل ۲**: سامانه‌های ترمودینامیکی ساده
- **فصل ۳**: کار

## فایل‌ها

| فایل                       | نقش                                                                                       |
| -------------------------- | ----------------------------------------------------------------------------------------- |
| `data.js`                  | meta، دسته‌ها، کتاب‌ها، واژه‌نامه؛ جلسه‌ها را از `getUnits("thermo", "sessions")` می‌گیرد |
| `sessions/s01.js`–`s03.js` | هر جلسه یک فایل؛ با `registerUnit` ثبت می‌شود                                             |
| `widgets/<key>.js`         | هر ویجت یک فایل (`thermometer`، `pvd`)                                                    |
| `problems.js`              | مسائل منتخب فصول ۱–۳                                                                      |

## فعال‌سازی

پک با `id: "thermo"` ثبت می‌شود. از صفحهٔ کتابخانه می‌توانید آن را فعال کنید (پک اپتیک به‌صورت پیش‌فرض اول لود می‌شود).

## یادداشت حق‌تألیف

متن مسائل و ساختار از کتاب اقتباس آموزشی شده است. برای مطالعهٔ کامل به نسخهٔ اصلی کتاب مراجعه کنید.
